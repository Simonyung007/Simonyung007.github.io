Swiss or Miss

Simulation Roguelike | Become a Graphic Designer

Overview

Swiss or Miss is a single-player simulation roguelike developed in Unity as a team project for Game Project Studio 1. The player takes the role of a graphic designer who must complete poster commissions based on different client requirements.

Players must balance creativity and strategy while managing their available resources, stress, and deadlines to complete each commission successfully.

Core Gameplay

During each commission, the player receives a set of requirements from a client and creates a poster using the design elements they have collected.

Players can freely arrange and transform elements on the poster while deciding how to use their available resources. Their design decisions affect how successfully they satisfy the client's requirements.

  • Receive poster requirements from different clients
  • Collect and use different design elements
  • Place and arrange elements freely on the poster
  • Move, scale, and rotate poster elements
  • Manage resources, stress, and deadlines
  • Complete poster commissions and progress through the game

My Contribution

I worked mainly as a Gameplay Programmer and was responsible for developing several of the interaction systems used in the poster editor.

  • Element selection system
  • Drag-and-drop poster element system
  • Move, scale, and rotation tools
  • Element layering behaviour
  • History and undo system
  • Grid overlay system
  • Tutorial level creation

Development Reflection

Developing Swiss or Miss gave me more experience with Unity gameplay programming, UI interaction, input handling, debugging, and integrating different gameplay systems while working in a team project.

One of the main challenges was developing the poster editor. The player needed to freely select, move, scale, and rotate different elements while keeping the controls responsive and preventing conflicts between the editor interactions and other UI screens.

Through this project, I learned more about designing interconnected gameplay systems and solving interaction problems that appear when multiple UI and input systems need to work together.
