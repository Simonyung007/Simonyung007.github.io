Swiss or Miss

Roguelike Autobattler | Graphic Design Simulation

Overview

Swiss or Miss is a single-player graphic design simulation game developed in Unity as a team project for Game Project Studio 1. The player takes the role of a graphic designer who must create posters based on different client requirements.

Rather than simply creating any design they want, players must make strategic decisions around limited design elements, time, stress, and changing client demands while trying to produce a poster that satisfies the client.

Core Gameplay

Each job begins with a client request containing different requirements and preferences. Players must then obtain design elements such as shapes, colours, and text before using them to construct their poster.

Actions take time and can affect the player's stress, so the player must decide when to collect elements, work on the poster, rest, or respond to client requests before reaching the deadline. Once the poster is submitted, it is evaluated based on how well it satisfies the requirements.

  • Read client requirements and design preferences
  • Obtain shapes, colours, and text through the element system
  • Create and arrange a poster using the collected elements
  • Manage limited days and stress
  • Respond to unexpected client requirement changes
  • Submit the poster for evaluation
  • Receive a score based on the completed requirements
  • Progress to the next client

Poster Editor

The poster editor is the main interactive part of Swiss or Miss. It was designed as a simplified graphic editing tool inspired by applications such as Photoshop and Canva.

Players interact with the editor mainly using the mouse. Poster elements can be selected and directly manipulated so that the player can experiment with different layouts while trying to satisfy the client's requirements.

  • Select poster elements
  • Drag and reposition elements
  • Scale elements
  • Rotate elements
  • Manage element layers
  • Undo previous editing actions
  • Use a grid overlay to assist with layout

Game Design & Visual Style

Swiss or Miss uses a Swiss-style visual direction with minimalist layouts, bold colours, flat graphics, and strong use of spacing and grids.

The game is heavily UI-driven, with most gameplay information and interaction presented through menus and interface elements instead of a traditional 3D game world.

Development Reflection

Developing Swiss or Miss gave me more experience with Unity gameplay programming, UI interaction, mouse input, debugging, and integrating multiple gameplay systems within a team project.

One of the biggest technical challenges was developing the poster editor. Different objects needed to be selected, moved, scaled, rotated, layered, and edited while still allowing the rest of the game's UI to function correctly.

This meant I had to consider how multiple interaction systems worked together rather than treating each feature separately. I also gained more experience identifying problems through playtesting and improving how players interact with the game.
