Swiss or Miss

Game Project Studio 1 Team Project

Engine: Unity

Genre: Roguelike / Strategy / Creative

Platform: PC

Project Type: University Team Project

My Role: Gameplay Programmer

About the Game

Swiss or Miss is a single-player roguelike game where the player takes the role of a graphic designer completing poster commissions for different clients.

Each client provides different design requirements and the player must create a poster using the available design elements while managing resources, stress, and deadlines.

The game combines creative poster composition with strategic decision-making, allowing players to decide how to use their available resources and complete each task.

My Contribution

I worked mainly as a Gameplay Programmer and was responsible for developing the interactive poster editing systems used during gameplay.

  • Drag and drop poster elements onto the board
  • Element selection system
  • Move, scale, and rotation tools
  • Poster board interaction
  • Element layering behaviour
  • Grid overlay system
  • UI and input interaction
  • Gameplay system integration

What I Learned

This project gave me more experience working with Unity gameplay programming, UI interaction, input handling, debugging, and integrating different systems into a team project.

One of the main challenges was making the poster editor feel responsive while allowing players to freely select, move, scale, and rotate different UI elements without creating conflicts between the gameplay controls and other UI screens.
